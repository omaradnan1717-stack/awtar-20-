إضافة فواتير المكاتب — مطعم وكافيه أوتار

التفعيل مرة واحدة:
1. افتح مشروع Supabase الحالي ثم SQL Editor ثم New query.
2. الصق محتوى invoices-setup.sql واضغط Run.
3. على GitHub ارفع index.html وsecure.js فقط إلى نفس مكان الملفين الحاليين ثم Commit changes.
4. افتح البرنامج بحساب المدير أو الموظف. المدير يفتح حساب المكتب ثم «فواتير المكتب». الموظف يجد قسم «فواتير المكاتب» في صفحته ويختار المكتب.

الاستخدام:
اختَر صورة من الاستوديو أو ملف PDF، أو صوّر الفاتورة بالكاميرا.
أدخل التاريخ ورقم الفاتورة والمبلغ والملاحظات عند الحاجة واضغط حفظ.
كل ملف بحد أقصى 10 ميغابايت. يمكن حفظ عدة ملفات لنفس الفاتورة.
اضغط فتح لمشاهدة الفاتورة، أو تنزيل لحفظها؛ على iPhone يمكن استخدام مشاركة ثم حفظ في الملفات.
الفواتير متاحة للمدير والموظفين المخوّلين بعد تسجيل الدخول لنفس المشروع. الموظف يرفع ويفتح الفواتير، ولا يملك صلاحية حذفها أو تعديل بياناتها. يظهر قسم الفواتير للموظف بعد تسجيل الدخول أو الضغط على تحديث الحسابات.
الرفع لا يسجل ديناً أو مصروفاً أو تسديداً تلقائياً.
ملفات الفواتير محفوظة منفصلة عن النسخ الاحتياطي JSON الحالي للبرنامج.
إذا انقطع الاتصال قبل تأكيد الحفظ، اضغط تحديث الفواتير قبل إعادة الرفع.
لا تمسح بيانات المتصفح ولا تغيّر إعداد ربط المشروع.
